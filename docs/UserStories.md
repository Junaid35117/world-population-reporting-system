# User Stories

## US-01

As a user, I want to view all countries ordered by population so that I can compare countries by population size.

## US-02

As a user, I want to view countries in a selected continent so that I can analyze regional data.

## US-03

As a user, I want to view cities within a country.

## US-04

As a user, I want to view capital cities by population.

## US-05

As a user, I want to generate world population reports.

## US-06

As a user, I want to view language statistics for the most spoken languages.
